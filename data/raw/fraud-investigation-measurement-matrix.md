# Fraud Investigation Measurement Matrix

## 1. Case Management Metrics

| Metric | Definition | Target |
|--------|------------|--------|
| Case Aging > SLA | % cases exceeding SLA | <5% |
| Escalation Rate | % cases escalated | <10% |
| Repeat Fraud Rate | Same customer/entity | <3% |
| Investigator Productivity | Cases per FTE | Benchmark Based |

---

## 2. Quality Assurance Metrics

| Metric | Description | Target |
|--------|------------|--------|
| QA Error Rate | % reviewed cases with errors | <5% |
| Documentation Completeness | Required fields filled | 100% |
| Regulatory Filing Timeliness | SAR/STR filed within timeline | 100% |

---

## 3. Loss Analysis

| Category | Measurement |
|----------|-------------|
| Gross Fraud Loss | Total monetary loss |
| Net Fraud Loss | Loss - Recovery |
| Avoided Loss | Prevented transactions |
| Customer Reimbursement | Compensation paid |
