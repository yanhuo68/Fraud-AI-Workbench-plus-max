# User Manual: ERD Diagram

Visualize your database schema.

## How to Use
1.  **Load Data**: You must have data loaded (via Upload or Demo SQL).
2.  **View Diagram**: The tab explicitly draws your tables and connections.
3.  **Legend**:
    *   **`*`**: Primary Key (Unique ID).
    *   **`fk` / lines**: Foreign Keys (Links between tables).
    *   **`string/int`**: Data types.

## Tips
*   **Too cluttered?**: Use the slider at the top to show fewer columns per table.
*   **Missing lines?**: Go back to "Upload Data" and ensure you ran the "Execute Demo SQL" step to establish relationships.
