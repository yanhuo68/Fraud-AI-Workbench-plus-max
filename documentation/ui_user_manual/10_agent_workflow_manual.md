# User Manual: Agent Workflow

Understand how the Fraud Detection AI Workbench works under the hood.

## Overview
This tab displays a diagram of the system's architecture. It is primarily educational.

## Components
*   **Ingestion**: How data gets in (Uploads/DB).
*   **Processing**: How data is prepared (Vector Store/Graph).
*   **Agents**: The specialized AI workers (SQL Agent, Search Agent, etc.) that power the tabs.
