# User Manual: SQL RAG

Ask questions about your structured database using plain English.

## How to Use
1.  **Select Tables**: In the sidebar, check the tables you want to query (e.g., `transactions`, `users`).
2.  **Ask a Question**: Type your question in the chat box.
    *   *Example*: "How many fraud cases occurred in New York last month?"
    *   *Example*: "Show me the top 5 merchants by transaction volume."
3.  **View Results**:
    *   The system generates and runs a SQL query.
    *   You see the resulting data table and an automatic chart (if applicable).
    *   The AI summarizes the answer for you.

## Tips
*   **Be Specific**: Mention column names if you know them (e.g., "group by category").
*   **Check the SQL**: You can expand the "Generated SQL" section to verify what the system did.
*   **Errors?**: If a query fails, try rephrasing or simplifying the question.
