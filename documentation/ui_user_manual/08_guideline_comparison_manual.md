# User Manual: Guideline Comparison (Fraud Assessment)

Use AI to act as a "Senior Investigator" and manually review specific cases against your policies.

## How to Use
1.  **Select Table**: Choose your transactions table.
2.  **Select Case**: Choose a specific Transaction ID (row) to investigate.
3.  **Select Guidelines**: Pick which policy documents apply (e.g., "AML Policy").
4.  **Generate Assessment**: Click the button.

## The Output
You will receive a generated report containing:
*   **Risk Score**: High, Medium, or Low.
*   **Reasoning**: A detailed explanation of *why* this transaction is risky, citing specific clauses from your selected guidelines.
*   **Recommendation**: Advice on next steps (e.g., "File SAR", "Close Case").
