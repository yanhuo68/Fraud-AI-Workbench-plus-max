# User Manual: Graph RAG

Explore hidden connections between entities (Users, IP addresses, Devices).

## Prerequisites
*   **Rebuild Graph**: If prompted, click **"Rebuild Graph"** in the sidebar.

## How to Use
1.  **Ask Relationship Questions**: Unlike SQL (which counts things), Graph RAG is good at connecting things.
    *   *Example*: "How is user Alice connected to user Bob?"
    *   *Example*: "Find rings of users sharing the same device."
2.  **Explore the Graph**: Use the interactive visualization to zoom in/out and drag nodes around.
3.  **Segments**: Use the controls to view specific parts of the graph (e.g., just the "Document" connections).

## Tips
*   **Upload Data**: Uploading CSVs populates the graph with real entities (Users, Transactions).
*   **Upload Docs**: Uploading policies links those entities to rules.
